# GDG Marseille — Site web officiel

La communauté tech de Marseille, propulsée par Google.

## À propos du projet

Site vitrine du GDG Marseille (Google Developer Group).  
Association loi 1901, nous fédérons développeurs, étudiants et entreprises autour d'événements tech.

## Technologies utilisées

- HTML5 / CSS3 / JavaScript (Vanilla)
- Git & GitHub pour le versionnage
- Déployé sur GitHub Pages (ou Cloudflare à terme)
- Intégrations futures : Bevy, Brevo, HelloAsso
